流動球幕天文館 · 自動播放編寫教學

本頁依 Digitalis《StratoScript 24.4 Reference》（Nightshade G3）、《StratoScript 21.7 Reference》（NG）與《How to Create Augmented Lessons》三份官方文件整理，並附上一個可以邊點邊學的 StratoScript 腳本產生器。全部內容離線可用。

一個流動球幕系統由三層組成

層是什麼你寫什麼
硬體Digitarium 流動球幕（半球投影、魚眼鏡頭、音響、cove 燈）—
模擬軟體Nightshade（G3 / NG），即星空模擬引擎，有太陽系天體、恆星、星座、深空天體資料.sts 腳本（StratoScript）
操作介面Universal Console（平板/遙控網頁控制台）Augmented Lesson 教學頁（index.html）

「自動播放」= 兩種東西：

1️⃣ StratoScript（.sts）——一行的指令依序執行：改日期、快轉時間、飛到木星、疊圖、播音樂……腳本跑完自動停。

2️⃣ Augmented Lesson——一個簡單 HTML 頁面，顯示在控制台上：左邊旁白給講者看，右邊按鈕/縮圖一點就播放腳本或把圖投上穹頂。適合「講到哪、點到哪」的互動教學。

版本注意：G3（24.4）新增了 cascading 設定（set 的 TAXON_ATTRIBUTE）等能力；NG（21.7）腳本大部分可直接在 G3 播。要寫「兩台都跑得動」的腳本，避開 G3 專屬分類學 set 寫法即可。

② 快速上手：五分鐘寫出第一支腳本

目標：傍晚的香港夜空 → 快轉看星星轉動 → 縮時軌跡。把下面內容存成 my_first_show.sts（UTF-8 編碼）：

# 我的第一支球幕腳本
require projection_type fisheye version 21.1.1 release professional

# 場景歸零：乾淨的夜空
clear state natural
flag atmosphere off
flag cardinal_points off
date local 2026-11-06 20:00:00
moveto lat 22.3 lon 114.17 duration 5
wait duration 5

# 快轉：每秒 = 15 分鐘模擬時間，看星空轉 2 分鐘
timerate rate 900
wait duration 120
timerate rate 1

三個關鍵觀念立刻記住：

1️⃣ wait 是心跳——沒有 wait，前面所有動畫會被下一行指令立刻打斷，觀眾什麼都看不到。

2️⃣ 凡是帶 duration 的動畫指令（moveto／flyto／date／zoom…），後面幾乎都要跟一支 wait duration ≥ 動畫秒數。

3️⃣ 第一行用 require 聲明需要的投影模式與最低版本，播放器與操作員都會知道這支腳本的前提。

③ 檔案結構與部署

lessons/
└── 你的出版社名稱/              ← PUBLISHER（建議用自己獨一無二的名字）
    └── my_lesson/               ← 每個課程一個資料夾
        ├── index.html          ← 教學頁（互動課程必備）
        ├── scripts/            ← .sts 腳本（慣例）
        │   ├── 01_intro.sts
        │   └── show_all.sts
        ├── media/              ← 投上穹頂的完整媒體檔（慣例）
        │   └── diagram.png
        └── thumbs/             ← 縮圖，給控制台頁面顯示（慣例）
            └── diagram.png

部署流程：把 lessons/ 放到媒體母碟 → 同步到 Digitarium 主機內建硬碟 → Universal Console 的 Lessons 頁籤就會出現你的課程。

打包規範：發佈 zip 的頂層必須是 lessons/PUBLISHER/LESSON/。路徑區分大小寫（cat.jpg ≠ Cat.jpg），腳本裡的路徑一律相對於「腳本自己所在目錄」，上一層用 ../。

④ StratoScript 語法基礎

一行一指令，參數成對

COMMAND ARG1 VALUE1 ARG2 VALUE2 ...
select object Jupiter          # 選中木星
flag atmosphere on             # 開大氣
date utc 1999-08-11T12:00:00  # 跳到指定時刻
規則說明
一行 = 一指令以換行結尾。字串值內要換行用 \n；長指令可用行尾 \ 續行
空白是分隔符值含空白必須加雙引號："This is a value."；值內的引號用 \"
指令／參數名不分大小寫FLAG = flag；但參數值區分大小寫（on ≠ ON 的物件名、天體名都要對準）
參數對順序自由moveto lat 22 lon 114 duration 5 與 moveto duration 5 lon 114 lat 22 等價
註解# 起頭到行尾被忽略；要顯示 # 本身用 \#
編碼檔案存 UTF-8，副檔名 .sts
必要參數要一次給齊同一行內給完，不能分兩行補
好習慣：① 開頭寫 require；② 每幕開頭 clear state natural 或重設 flag，避免上一幕殘留；③ 結尾把時間速率、flag 復原，方便連播下一支。

⑤ 標準參數型別（看懂文件的前提）

型別意義例子
DATE_TIMEISO8601 日期時間，可只給日期或只給時間1918-11-11、20:30:00、-200-03-22T13:33:00
DISTANCE數字＋可選單位（預設公尺）1au、10km、50%（當前距離的百分比）
FADER0～1 的滑桿值（透明度、音量等）0 全透明／靜音，1 全開
RGB(A)三（四）個 0~1 值1,0.5,0、"0.33,0.2,0.9,0.3"
SECONDS秒（可小數）2.5
ON_OFFon/1 或 off/0；toggle 反轉flag stars off
DEGREES十進位角度22.3、-540.23
RIGHT_ASCENSION / DECLINATION赤經時分秒／赤緯度分秒12h5m4.5s、-9d4m3.2s

座標系（COORDINATE_SYSTEM）——媒體定位的核心

座標系參數 A參數 B什麼時候用
domealtitudeazimuth疊圖／字幕首選。固定於球幕（跟著焦點方位），不被鏡頭移動影響
viewportxposypos魚眼全畫面媒體：配 scale fill 就是「fulldome」投法
horizontalaltitudeazimuth360° 全景照／影片：配 scale 360 可環景環繞
equatorial / j2000radec把媒體釘在天球某個天區（隨星空轉動）
geocentriclatlon貼在天體表面
galacticradec銀道座標的天區
dome 座標的方位角以「焦點方位的反方向」為 0° 逆時針計——多半劇場把觀眾席主視線設在焦點上，所以旁白區大約在 azimuth 180，這也是把示意圖放「觀眾正前方」最常用的值。

鋪場與狀態

require 聲明播放需求——建議永遠當腳本第一行 ✦
require projection_type fisheye version 21.1.1 release professional

projection_type：fisheye / perspective。release：basic / community / professional（basic 只能在太陽系內移動）。不給 version 會被當成舊版行為（moveto 沒有緩入緩出）。

clear 一鍵清場，回到乾淨夜空 ✦
clear state natural   # 關掉所有線條標籤、開行星恆星、回到初始視野

每幕開頭先清場，等於「重設按鈕」；比逐個 flag off 省事且不易漏。

flag 開關單一顯示項目 ✦
flag constellation_lines on     # 星座連線
flag atmosphere off             # 關大氣（離開地球看行星系必備）
flag planet_orbits on           # 行星軌道線
flag time_lapse on              # 縮時軌跡（星流、日行跡）
flag cardinal_points off        # 東南西北方位點

常用旗標：stars、star_names、constellation_art/names/boundaries、planet_names、planet_orbits、ecliptic_line、equator_line、milky_way→sky、landscape、clouds、moon_scaled、track_object、show_tui_datetime、script_gui_debug（除錯）。值可用 toggle 反轉。

set 細部設定：標籤大小、文化、時區、太陽月亮尺度…✦
set label_scale 0.75                # 標籤縮小
set home_planet "Solar System Observer"  # 觀測點搬到太陽系俯瞰點
set sky_culture chinese             # 中國星空文化（三垣二十八宿）
set sky_locale zh_HK                # 天區標籤用繁體中文
set moon_scale 4                   # 月亮放大 4 倍（配 flag moon_scaled）
set time_zone Asia/Hong_Kong
# G3 專屬：cascading 分類學屬性
set planetary.planets.orbit_color 1,0,0,1 duration 5
color 改線條顏色
color property planet_orbits color 1,1,0
color property constellation_lines color "0.5,0.7,1,0.6"

property 可用：constellation_lines / constellation_art / ecliptic_line / equator_line / planet_orbits / azimuthal_grid / equatorial_grid / cardinal_points …

時間與日期

date 跳日期時間；sidereal 步進是行星教學的殺手級用法 ✦
date local 2026-11-06 20:00:00
date utc 1999-08-11T12:00:00
date load current relative 7          # 一週後的現在
date relative 365 duration 30 steps 365  # 一年一天一步 → 日行跡
date sidereal 2                        # 前進 2 個恆星日：星空不動、行星移動

duration＝動畫秒數；steps＝改用等步進而非平滑插值。恆星日步進是演示「行星相對星空移動（順行/逆行）」的標準手法。

timerate 時間流速：1＝正常，900＝每實秒 15 分鐘 ✦
timerate rate 900
wait duration 60
timerate rate 1          # 一定要記得調回來
timerate action pause    # 時間凍結

攝影機與移動

moveto 在原地/換天體移動落點與視線 ✦
moveto lat 22.3 lon 114.17 duration 5
moveto object Sun lat 82 alt 4AU look_at on duration 10   # 飛到太陽北極上方俯瞰

參數：lat / lon / alt / heading / pitch / roll / land / look_at / object / duration。可中途換錨定天體（object）；look_at on 會看向錨定天體。⚠ 兩個 moveto 重疊時後者打斷前者。

flyto 直線飛到某天體附近 ✦
flyto object Mars alt 10km duration 20
wait duration 20

anchor：geosync（預設，定在對方經緯度上空）/ follow（跟著天體但相對星空固定，可看它自轉）。飛到後該天體自動被選中。

zoom 變焦望遠鏡；auto in 一鍵看衛星系統 ✦
select object Jupiter
zoom auto in             # 自動框住木星＋衛星系統
wait duration 15
zoom fov 60 duration 5  # 手動設視野角
zoom auto initial       # 回到初始視野

選中與焦點

select / deselect 選天體、星座、恆星、深空天體 ✦
select object Mars pointer off     # pointer off 不畫高亮圈
select constellation ORI           # 獵戶座（連線+範圍）
select nebula M31                  # 仙女座星系（M/NGC/IC 編號）
select hp 80737                    # 用 Hipparcos 編號選亮星（織女一）
deselect                           # 取消選中

穹頂媒體

image 疊圖：示意圖、標題卡、 fulldome 圖 ✦
# dome 座標疊示意圖（漸顯 2 秒）
image action load name diagram filename media/diagram.png alpha 1 \
  coordinate_system dome altitude 45 azimuth 180 scale 55 duration 2
wait duration 20
# fulldome 全幅圖
image action load name fd filename dome.png alpha 1 coordinate_system viewport scale fill
# 360 環景
image action load name pano filename pano.jpg alpha 1 coordinate_system horizontal scale 360
# 用完就丟，保持效能
image action drop name diagram

重點：預設 alpha 0（全透明），必須給 alpha；透明背景用 PNG；persist on 讓圖在腳本結束後留著；rotation 順時針轉圖。

text 穹頂字幕（實驗性）✦
text action load name title string "從地心到日心" font_size 8 \
  coordinate_system dome altitude 40 azimuth 180 alpha 0
text name title alpha 1 duration 2     # 漸顯
wait duration 6
text name title alpha 0 duration 2     # 漸隱

字串支援 <b><i><sup><sub> 標記與 \n 換行；font_size 是「字高約幾度」；載入後只有位置、旋轉、alpha 可改。

audio / video 音訊與影片 ✦
audio action play filename music.ogg name intro volume 0.8
wait duration 20
audio action drop name intro

video action play name film filename intro.mpg alpha 1 coordinate_system viewport scale fill
wait duration 15
video action stop name film
腳本結束或被停止時，它啟動的音訊/影片會跟著停——旁白音軌要覆蓋整段就在同一支腳本裡播完。高解析影片（2k×1k 以上）需用 vdec 外掛編碼。
landscape / meteors / cove_lights 地景、流星雨、穹緣燈
landscape action load name HK body Earth type spherical texture hk.png top_altitude 25
meteors zhr 10000 ra 30 dec 80       # 流星暴（輻射點 J2000）
cove_lights color 1,0,1,1 duration 15  # 穹緣燈漸變到洋紅

進階（依需要再學）

body 自訂天體：小行星、彗星、人造衛星

用軌道根數（半長軸、離心率、傾角…）新增太陽系天體，可掛 3D 模型與貼圖。長指令、參數多，建議從官方範例改。

layer / point_cloud 資料圖層與點雲
layer name sea reference_frame Earth action load url imagery/sea.TIFF
point_cloud action load name sdss filename galaxies.tsv coordinate_system j2000
script / configuration / sky_culture 腳本串接與系統
script action play filename part2.sts   # 跳到下一支（本支結束）
script action pause                     # 暫停等講者按播放
configuration action save name myshow   # 存/載設定檔
sky_culture action load path MyCulture  # 載入自訂星空文化

⑦ 球幕媒體製作要點

投影的真相：半球曲面

穹頂是半球面，播放器把平面媒體經 dome warp 貼到球面上。所以你只需要準備平面母版，不用自己做魚眼變形；但構圖要按「最終會被貼在哪裡」來設計：

媒體類型母版規格播放方式
示意圖／字幕卡（疊在星空上）16:9（1920×1080）或正方形皆可，透明背景 PNG，內容放在中央安全區coordinate_system dome + scale（最大角尺寸，度），放 azimuth 180 altitude 45 面向觀眾
Fulldome 全幅正圓魚眼構圖（1:1 方形畫布、圓形內容）coordinate_system viewport scale fill
360° 環景2:1 等距圓柱投影coordinate_system horizontal scale 360
縮圖256×256 或 320×180只給控制台頁面用，放 thumbs/
對比度與過曝：球幕亮度低，純白會刺眼、純黑會「破洞」。底色用深藍（如 #050810）80% 透明度疊在星空上，文字用暖白（#f4f1e8）。
字要夠大：字高在穹頂上至少 2~3° 才可讀；示意圖正文約 12pt 相對 1080p 高度才安全。座位區兩側的畫面會被壓縮，重要內容不要放極邊緣。

⑧ Augmented Lesson 教學頁製作

教學頁會顯示在 Universal Console 上：div.narration 的旁白在左（給講者看）div.action 的互動元素在右（一點就播）。控制台會停用外部 CSS 與 JS，所以只能用內建 class 與 inline style，保持簡單。

<html><body>
# 必要的 4 個 meta：課程索引就靠它們
<meta name="category" content="你的出版社">
<meta name="pagename" content="從地心到日心">
<meta name="rating"   content="9+">
<meta name="language" content="zh_HK">

<h2>第一幕：住進地心說</h2>
<div class="narration">
  <p>旁白：先讓觀眾感受古人看到的星空……</p>
</div>
<div class="action">
  # 按鈕：執行一支腳本
  <div class="effect" data-type="script" data-value="scripts/01_intro.sts"
       data-transport="false">播放：天球旋轉</div>
  # 按鈕：執行單條指令
  <div class="effect" data-type="command" data-value="timerate rate 900">快轉時間</div>
  # 縮圖：點了把 media/ 的完整圖投上穹頂
  <img src="thumbs/diagram.png" data-type="image" data-value="media/diagram.png" title="示意圖">
</div>
</body></html>
class效果
narration旁白文字（螢幕左側）
action互動區（紅框、右側）
effect把 div 變成按鈕（需配 data-type/data-value）
uc-collapsible可折疊區塊（內需有 <h2> 當標題）；加 ancillary 預設收起

data-type 可用：command（單條指令）/script（整支腳本）/image/video/audio。媒體類型的 data-value 填相對路徑，可用 data-coordinate_system、data-xpos、data-ypos、data-scale、data-rotation、data-clone 指定穹頂位置。data-transport="false" 隱藏播放器控制條。圖片建議附 data-author、data-license、data-link 註明出處授權。

下方產生器有「互動元素片段」分頁，填表即可產生這些 HTML。

⑧+ 教學腳本設計方法論

單幕黃金結構（約 60–90 秒）

# ── 幕開始：清場 ──
clear state natural
flag ...（這一幕需要的）
# ── 鉤子：先給現象 ──
...現象動畫 + wait
# ── 解釋：疊示意圖/字幕 ──
image action load ... alpha 0
image name ... alpha 1 duration 2
wait duration 20
# ── 幕結束：自己清自己 ──
image action drop name ...
text action drop name ...
  • 每幕自己清自己：誰 load 的媒體誰 drop。這樣任意跳幕播不會殘影。
  • 先現象後原理：先讓觀眾「看到怪事」（行星倒退），再給解釋模型。
  • 節奏：一張圖停 15–25 秒；旁白語速約每秒 4 字，對稿配 wait。
  • 總控腳本：把各幕 .sts 合成一支 show_all.sts 全自動播放；分段腳本則給互動教學用。同一內容兩種形態。
  • 誠實教學：模型近似處明說（「圖中視差角大幅誇大」），觀眾信任感反而更高。

⑨ 常見錯誤與排解

症狀原因
畫面一閃而過，什麼都沒看到動畫指令後沒有 wait；或下一行指令把動畫打斷
圖片載入後完全看不到image 預設 alpha 0（全透明）——要給 alpha 1
找不到檔案路徑區分大小寫；路徑相對於腳本而非課程根目錄；上一層要 ../
旁白音樂突然斷掉腳本結束/被停會殺掉它啟動的音訊；長音軌要放在同一支腳本內播完
moveto / date 動畫亂跳兩個同類動畫指令時間重疊，後者打斷前者；拉開 wait
moveto 沒有緩入緩出腳本缺 require ... version，被當成舊版行為
圖釘在星空上到處跑（或不動）座標系選錯：dome 固定於劇場、equatorial 跟星空轉、viewport 是魚眼全畫面
腳本行為在新舊機器不一致G3 專屬寫法在 NG 不支援；要雙機兼容就避開 cascading set 與新參數

示範「先現象、後原理、每幕自清」的完整寫法（節錄自本工作區實際課程包）。


# ============ 第 2 幕：火星逆行 ============
clear state natural
flag planet_orbits on
flag planet_names on
date local 2027-01-25 21:00:00
moveto lat 22.3 lon 114.17 duration 5
wait duration 5

# 恆星日步進：星空凍結、只有行星在動
date sidereal 2
wait duration 1
# ……重複 60 次（火星走完逆行弧）……

# 疊示意圖解釋
image action load name retro filename media/03-retrograde-geometry.png alpha 0 \
  coordinate_system dome altitude 45 azimuth 180 scale 55
image name retro alpha 1 duration 2
text action load name t-r2 string "地球超車火星——倒退只是視線錯覺" font_size 3.2 \
  coordinate_system dome altitude 12 azimuth 180 alpha 0
text name t-r2 alpha 1 duration 2
wait duration 25

# 自己清自己
image name retro alpha 0 duration 2
text name t-r2 alpha 0 duration 2
wait duration 2
image action drop name retro
text action drop name t-r2
